# Genis — управление Windows жестами

<p align="center">
  <img src="assets/logo.png" width="132" alt="Genis — пиксельная обезьяна">
</p>

<p align="center"><b>Сделано командой Crazy Monkeys</b></p>

Приложение для Windows: смотрит в веб-камеру, распознаёт руки и превращает жесты
в действия — движение мыши, клики, запуск программ, горячие клавиши, громкость,
яркость, окна и рабочие столы.

Живёт в системном трее, настройки — в обычном окне. **Свои жесты можно записать**:
держишь позу полторы секунды — приложение запоминает её (одной или двумя руками)
и даёт повесить на неё любое действие.

Всё считается локально. Видео никуда не отправляется.

## Особенности

### Распознавание жедов
- **Одиночные жесты** (одна рука):
  - Указание указательным пальцем — движение курсора
  - Щипок указательным и большим пальцами — клик мыши (перетаскивание при удержании)
  - Жест «ОК» (щипок + три пальца вытянуты) — проводник (Win+E)
  - Большой палец вверх — громкость больше
  - Большой палец вниз — громкость меньше
  - Жест «Рок» (указательный и мизинец вверх) — play/pause в плеере
  - Кулак — ничего (можно назначить своё действие)

- **Двурукие жесты** (обе руки simultaneous):
  - Две ладони — Win+Tab — все окна
  - Два кулака — play/pause в плеере (по умолчанию, вместо разрушительного Win+D)
  - Двойной щипок — правый клик мыши

### Свои жесты
- Записывайте жесты через меню «Жесты → Записать свой жест»
- Покажите жест камере и держите его ~1.5 секунды
- Выберите действие (запуск программы, горячая клавиша, действие системы)
- Дайте имя и сохраните
- Если при записи в кадре обе руки — жест сохранится как двурукий
- Свои жесты имеют приоритет над встроенными при уверенном совпадении (score ≥ 0.55)

### Настройки
Открыть через значок в системном трее → Настройки

- **Камера**:
  - Выбор устройства с дружественными именами
  - Разрешение (640×480 — быстрее, 1280×720 и выше — детальнее)
  - Сколько рук отслеживать (1 или 2 — для двуруких жестов)
  - Зеркалирование картинки
  - Показать landmarks (для отладки)

- **Настройки**:
  - Стабилизация жеста (кадры для подтверждения)
  - Удержание жеста (минимальное время до срабатывания)
  - Удержание двумя руками (отдельная пауза для жестов двумя руками)
  - Коールドاون (минимальное время между срабатываниями)
  - Чувствительность и сглаживание курсора
  - Мёртвая зона курсора
  - Скорость и направление прокрутки
  - Звуковые сигналы
  - Горячая клавиша паузы (по умолчанию Ctrl+Alt+Q)
  - Автозагрузка при входе в Windows
  - Показать окно при старте
  - Стартовать в режиме паузы

## Установка и запуск

### Требования
- Windows 10/11 (64-бит)
- Подключенная веб-камера
- Подключение к интернету для pierwszej загрузки модели

### Способ 1: Через установщик (рекомендуется)
1. Скачайте последнюю версию с [страницы релизов](https://github.com/ficksj/genis/releases)
2. Запустите `Genis-Setup.exe`
3. Следите инструкциям мастера установки
4. После установки Genis появится в системном трее

### Способ 2: Из исходного кода
1. Убедитесь, что установлен Python 3.14 или новее
2. Клонируйте репозиторий: `git clone https://github.com/ficksj/genis.git`
3. Перейдите в папку проекта: `cd genis`
4. Запустите скрипт настройки: `.\setup.ps1`
5. Дождитесь завершения загрузки зависимостей и модели
6. Запустите приложение: `.\run.bat` (или `.\run-debug.bat` для вывода консоли)

### Первый запуск
При первом запуске приложение:
1. Скачает модель распознавания руки (~4 МБ)
2. Создаст папку для настроек в `%APPDATA%\Genis`
3. Откроет окно с руководством по использованию
4. Начнёт обработки video с камеры по умолчанию

## Использование

### Основные управленя
- Клик правой кнопкой по значку в трее — открыть меню
- Левая кнопка по значку — показать/скрыть главное окно
- Горячая клавиша Ctrl+Alt+Q — глобальная пауза/возобновление работы

### Работа с жестами
1. Покажите руку(и) камере
2. Держите нужную позу достаточно долго (см. настройки удержания)
3. Genis распознает жест и выполнит связанное действие
4. Свои жесты проверяются первыми и имеют приоритет при совпадении ≥ 55%

### Запись собственных жестов
1. Выберите «Жесты → Записать свой жест» в главном окне
2. Покажите жест камере (одной или двумя руками)
3. Держите позу ~1.5 секунд пока идёт запись
4. Выберите действие для этого жеста
5. Введите название жеста
6. Нажмите «Сохранить»

### Управление приложением
- Значок в трее предоставляет доступ ко всем функциям
- Главное окно имеет четыре вкладки:
  - Обзор — текущие жесты и действия
  - Жесты — управление встроенными и собственными жестами
  - Камера — настройки видео capture
  - Настройки — тонкая настройка всех параметров

## Разработка

### Структура проекта
```
genis/
├── app/                    # Исходный код приложения
│   ├── __init__.py         # Метаданные пакета
│   ├── main.py             # Точка входа
│   ├── config.py           # Конфигурация и migrations
│   ├── paths.py            # Работа с путями и директориями
│   ├── controller.py       # Основной контроллер приложения
│   └── core/               # Ядро функциональности
│       ├── camera.py       # Capture видео и работа с MediaPipe
│       ├── engine.py       # Обработка жестов и генерация событий
│       ├── features.py     # Извлечение признаков из landmarks
│       ├── builtin.py      # Распознавание встроенных жестов
│       ├── custom.py       # Работа с собственными жестами
│       ├── actions.py      # Definition и исполнение действий
│       ├── system_win.py   # Windows-specifec функции ввода
│       ├── hotkey.py       # Реализация глобальных горячих клавиш
│       └── smoothing.py    # Фильтрация курсора (One Euro filter)
│   └── ui/                 # Пользовательский интерфейс
│       ├── main_window.py  # Основное окно приложения
│       ├── pages.py        # Страницы настроек и управления
│       ├── widgets.py      # Переиспользуемые UI компоненты
│       ├── action_dialog.py# Диалог выбора действия
│       ├── record_dialog.py# Мастер записи собственных жестов
│       ├── icons.py        # Генерация иконок и логотипа
│       └── theme.py        # Оформление приложения (тёмно-зеленая тема)
├── tests/                  # Юнит-тесты (>50 тестов)
├── tools/                  # Вспомогательные скрипты
│   └── make_assets.py      # Генерация ресурсов
├── assets/                 # Готовые ресурсы (иконки, логотип, шрифты)
├── build.ps1               # Скрипт сборки .exe через PyInstaller
├── setup.ps1               # Скрипт初始化 окружения
├── run.bat                 # Запуск без консоли
├── run-debug.bat           # Запуск с выводом консоли
├── genis.spec              # Спецификация PyInstaller
└── requirements.txt        # Зависимости Python
```

### Зависимости
- Python 3.14+
- PySide6 ≥ 6.8
- mediapipe ≥ 1.1.0 (Tasks API)
- opencv-contrib-python
- pynput
- numpy
- pygrabber
- PyInstaller (для сборки)

Все зависимости устанавливаются через `setup.ps1`.

### Тесты
Запустите все тесты командой:
```
.venv\Scripts\python.exe -m unittest discover -s tests
```

Текущее покрытие: 51 юнит-тест проходит, включая:
- Распознавание встроенных жестов
- Извлечение инвариантных признаков
- Работа с собственными жестами (1 и 2 руки)
- Проверка конфигурации и миграций
- Логика движка (стабилизация, удержание, drag)
- Парсинг горячих клавиш
- Разрешение названий камер

## Сборка и распространение

### Создание исполняемого файла
Исполняемый файл создается с помощью PyInstaller:

1. Убедитесь, что среда инициализирована: `.\setup.ps1`
2. Запустите сборку: `.\build.ps1`
3. Дождитесь завершения процесса (может занять несколько минут)
4. Исполняемый файл будет доступен по пути: `dist\Genis\Genis.exe`

### Создание установщика
Для распространения рекомендуется создать установщик с помощью Inno Setup:

1. Установите [Inno Setup](https://jrsoftware.org/isinfo.php)
2. Скопируйте собранный файл `dist\Genis\Genis.exe` в папку с скриптом установки
3. Запустите компиляцию скрипта установки через Inno Setup Compiler
4. Полученный установщик будет готов к распространению
